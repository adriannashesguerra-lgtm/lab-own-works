SECTION 1: Fundamentals of Statistics

Based on the module "Fundamentals of Statistics," exploring how data is converted into meaningful information. [cite: 5]

Intended Learning Outcomes

  1. Differentiate descriptive statistics from inferential statistics. [cite: 5]
  2. Classify variables and identify levels of measurement. [cite: 5]
  3. Discuss data collection methods and graphical presentations. [cite: 5]
Key Concepts
  • Statistics - A branch of mathematics that deals with the scientific collection, organization, presentation, analysis, and interpretation of data. [cite: 5]
  • Data - Pieces of information useful to the researcher. [cite: 5]
  • Variable - A characteristic or property of an individual to be measured or observed. [cite: 5]
  • Parameter vs. Statistic - A parameter describes an aspect of a population; a statistic describes an aspect of a sample. [cite: 5]

1.1 Descriptive vs. Inferential Statistics

Statistics is broadly divided into two areas: [cite: 5]

  • Descriptive Statistics: Methods concerned with collecting, describing (organizing, presenting, summarizing), and analyzing a set of data without drawing conclusions about a larger group. Example: Computing a class average. [cite: 5]
  • Inferential Statistics: Methods concerned with drawing conclusions, making predictions, or forecasting about the entire set of data based on a sample. Example: Testing if a new milk formulation improves psychomotor development. [cite: 5]

1.2 Variables and Levels of Measurement

Variables can be classified based on their nature and how they are measured: [cite: 5]

Type Sub-type Description & Examples
Quantitative (Numerical) Discrete Obtained by counting (e.g., number of children in a family). [cite: 5]
Continuous Obtained by measuring (e.g., distance traveled, temperature). [cite: 5]
Qualitative (Categorical) Attribute Categorizes or describes an element (e.g., gender, hair color). [cite: 5]

Levels of Measurement: [cite: 5]

  • Nominal: Names, labels, or categories with no implied order (e.g., Blood type). [cite: 5]
  • Ordinal: Data that can be ranked/ordered, but differences are meaningless (e.g., Sizes S, M, L). [cite: 5]
  • Interval: Differences are meaningful, but there is no true zero (e.g., Temperature in Celsius). [cite: 5]
  • Ratio: Differences and ratios are meaningful, and it has a true zero (e.g., Height, Speed). [cite: 5]

1.3 Data Collection and Sampling

Data can be Primary (first-hand information like interviews) or Secondary (collected for another purpose like journals). [cite: 5] Methods of collection include: Interview (Direct), Questionnaire (Indirect), Observation, Registration (Census), and Experimental. [cite: 5]

Random Sampling Methods: [cite: 5]

  • Simple Random: Each sample of the same size has an equal chance of being selected. [cite: 5]
  • Stratified: Population is divided into groups (strata), and a sample is taken from each. [cite: 5]
  • Cluster: Population is divided into strata, and entire strata are randomly selected. [cite: 5]
  • Systematic: Select a starting point and take every k-th piece of data. [cite: 5]

1.4 Summary Statistics

Measures used to describe data in just a few numbers: [cite: 5]

  • Central Tendency: Mean (arithmetic average, μ for population, x̄ for sample), Median (middlemost value), Mode (most frequent). [cite: 5]
  • Variability: Range (Maximum - Minimum), Variance (squared deviation from mean, s2), Standard Deviation (square root of variance, s). [cite: 5]
Raw Data → Sampling Methods → Collection (Interview/Survey) → Presentation (Graphs/Tables) → Summary Measures (Mean/SD)
SECTION 2: Hypothesis Testing

Based on the module "Inferential Statistics," detailing how to draw inferences about a larger group using samples. [cite: 4]

Intended Learning Outcomes

  1. Define the null and alternative hypotheses. [cite: 4]
  2. Distinguish between Type I and Type II errors. [cite: 4]
  3. Apply the appropriate statistical test (z-test or t-test) and follow the testing steps. [cite: 4]
Key Concepts
  • Null Hypothesis (Ho) - Assumes non-significance, lack of association, or no difference between variables. [cite: 4]
  • Alternative Hypothesis (Ha) - The opposite of the null; specifies an existence of a difference or relationship. [cite: 4]
  • Level of Significance (α) - The maximum probability of rejecting the null hypothesis when it is true (e.g., 1%, 5%). [cite: 4]
  • Test Statistic - A function of the random sample used to make the decision (e.g., z-statistic, t-statistic). [cite: 4]

2.1 Testing Errors and Tails

Because hypothesis testing is based on samples, there is a risk of error: [cite: 4]

Decision Null is True Null is False
Accept Ho Correct Decision Type II Error (β-error) [cite: 4]
Reject Ho Type I Error (α-error) [cite: 4] Correct Decision

A test can be One-tailed (directional, critical region at one extreme) or Two-tailed (non-directional, critical region on both sides). [cite: 4]

2.2 Common Statistical Tools

  • T-Test: Compares the means of two groups. Used when population standard deviation is unknown (uses sample standard deviation s). [cite: 4]
  • Z-Test: Used to compare means when the population standard deviation (σ) is known. [cite: 4]
  • ANOVA (F-Test): Compares multiple (three or more) samples simultaneously. [cite: 4]
  • Chi-Square Test: Finds significant association between two categorical (qualitative) variables. [cite: 4]
  • Pearson's r: Measures the correlation or association between two quantitative variables. [cite: 4]

2.3 Steps in Hypothesis Testing

  1. Formulate the null hypothesis (Ho) and alternative hypothesis (Ha). [cite: 4]
  2. Set the level of significance, α, and determine the direction of the test. [cite: 4]
  3. Determine the test statistic (z-test or t-test). [cite: 4]
  4. Determine the tabular (critical) value for the test (using degrees of freedom df if applicable). [cite: 4]
  5. Compute the test statistic using the formula. [cite: 4]
    z = (x̄ − μ) √n / σ
  6. Compare computed value with tabular value. Reject Ho if the absolute computed value is ≥ the absolute tabular value. [cite: 4]
  7. State the conclusion. [cite: 4]
State Ho / Ha → Choose α and Tail → Find Tabular Value → Calculate Test Statistic → Compare & Decide

3.1 George Polya's Four-Step Process

George Polya, the "Father of Problem Solving," developed a famous 4-step technique: [cite: 2]

  1. Understand the problem (Preparation): Read the problem multiple times and analyze it carefully to find out what is required. [cite: 2]
  2. Devise a plan (Insight): Choose an appropriate strategy (e.g., Guess and check, Look for a pattern, Make an orderly list, Draw a picture, Work backwards). [cite: 2]
  3. Carry out the plan (Execution): Implement the chosen strategy to solve the problem. [cite: 2]
  4. Look back (Verification): Check if the answer is reasonable and verify the logic. [cite: 2]

3.2 Key Formulas and Mathematical Strategies

Binet's Formula for the Fibonacci Sequence: Used to find the n-th term of the sequence. [cite: 2]

Fn = (1 / √5) [ ((1 + √5) / 2)n − ((1 − √5) / 2)n ]

Sum of the First n Terms (Arithmetic Progression): [cite: 2]

Sn = (n / 2) (a1 + an)

3.3 Sample Problems & Solutions

Problem 1: Three Consecutive Odd Integers
The sum of three consecutive odd integers is 75. Find the largest integer.
Solution: Let x = 1st odd integer. Then x+2 = 2nd, and x+4 = 3rd.
x + (x+2) + (x+4) = 75 → 3x + 6 = 75 → 3x = 69 → x = 23.
The largest is 23 + 4 = 27. [cite: 2]

Problem 2: Inscribed Square in a Circle
A square is inscribed in a circle with a radius of 10 cm. Find the area of the shaded region (outside circle, inside square). [cite: 2, 3]
Note from module correction: If a square is inscribed BY a circle (meaning the circle is inside the square), the diameter of the circle equals the side of the square. [cite: 2]
Diameter = 2 × 10 = 20 cm = side (s).
Area of square = 202 = 400. Area of circle = 3.14 × 102 = 314.
Area = 400 − 314 = 86 cm2. [cite: 2]

Problem 3: Team Work Rate
If Holee solves a problem set in 3 hours, and Angelo in 6 hours, how many hours together? [cite: 2, 3]
Solution: Rate = 1/3 + 1/6 = 1/t → 2/6 + 1/6 = 1/t → 3/6 = 1/t → t = 2 hours. [cite: 2]
